# 系统监控态势大屏（静态 HTML 原型）设计

日期：2026-08-11  
状态：已批准 · 静态原型已交付  
来源：`quickboot/sql/quickboot.sql` 监控相关 DDL + 运维投屏需求澄清  

## 1. 背景与目标

基于现有库表（登录、操作日志、前端埋点、慢 SQL、定时任务日志等），产出一张可投屏的**系统监控态势大屏**静态原型，用于评审布局与指标口径；数据全部为 mock，字段口径对齐 DDL，便于后续接真接口。

### 1.1 目标

1. 单文件静态 HTML，浏览器直接打开即可演示。  
2. 深色运维投屏墙视觉；布局为左中右三栏。  
3. 覆盖用户/登录、访问行为、请求与错误、慢 SQL、定时任务五组指标。  
4. 时间窗默认「今日」，可切换昨日 / 本周 / 近7天 / 本月。  

### 1.2 非目标

- 对接真实 API / 数据库  
- 写入 `quick-ui` 正式路由或权限体系  
- WebSocket 实时推送、告警规则引擎  
- 实现 OpenSpec `slow-sql-and-frontend-monitor` 模块代码（本设计仅消费其表结构口径）

## 3. 页面结构

```text
┌──────────────────────── 顶栏 ────────────────────────┐
│ 时间窗选择 │  QUICKBOOT 系统监控态势  │ 实时时钟 │
├──────────┬─────────────────────┬─────────────────────┤
│ 左上       │ 中上 核心 KPI 条      │ 右上                 │
```

## 4. 指标口径 ↔ DDL

本期数值均为 mock；下列口径为接真数据时的约定。

### 4.1 左栏

| 指标 | 来源表 | 口径 |
|------|--------|------|
| 总用户 | `sys_user` | `del_flag='0'` 计数（全量，不受时间窗） |
| 登录用户数 | `sys_logininfor` | 时间窗内 `status='0'` 的 distinct `user_name` |
| 登录成功 / 失败 | `sys_logininfor` | `status` 分组计数 |
| 登录趋势 | `sys_logininfor` | 按小时或按日分桶（随时间窗粒度） |
| 访问页数 | `sys_client_track` | distinct `page_visit_id` |
| 会话数 | `sys_client_track` | distinct `session_id` |
| 活跃用户 | `sys_client_track` | distinct 非空 `user_name` |
| 热门页面 Top5 | `sys_client_track` | `page_path` 聚合排序 |

### 4.2 中栏

| 指标 | 来源表 | 口径 |
|------|--------|------|
| 请求次数 | `sys_oper_log` | 时间窗内记录数 |
| 错误次数 | `sys_oper_log` | `status ≠ 0` |
| 慢 SQL 数（KPI） | `sys_slow_sql` | 时间窗内记录数 |
| 任务失败数（KPI） | `sys_job_log` | 失败 `status` 计数 |
| 请求 / 错误趋势 | `sys_oper_log` | 双轴折线；今日/昨日按小时，本周/近7天/本月按日 |

### 4.3 右栏

| 指标 | 来源表 | 口径 |
|------|--------|------|
| 慢 SQL 次数 / 均耗时 / 最大耗时 | `sys_slow_sql` | count / avg(`cost_time`) / max(`cost_time`) |
| 来源分布 | `sys_slow_sql` | `sql_source` 分组（如 BUSINESS / JIMU） |
| 最慢 SQL Top5 | `sys_slow_sql` | 按 `cost_time` 降序 |
| 任务成功 / 失败 | `sys_job_log` | `status` 分组 |
| 最近失败任务 | `sys_job_log` | 失败记录按 `create_time` 倒序 3～5 条 |

## 5. 交互与图表

- 顶栏时间窗切换后，整屏 KPI、图表、列表同步切换对应 mock 数据集。  
- 右上角显示实时时钟；可展示「模拟刷新」文案，不做真实轮询。  
- 图表：登录迷你趋势、热门页面条形/列表、请求-错误双轴折线、慢 SQL 来源饼图。  
- 列表：最慢 SQL Top5、最近失败任务。  

## 6. 技术与交付

| 项 | 约定 |
|----|------|
| 文件 | `docs/demo/system-monitor-dashboard.html`（单文件） |
| 依赖 | CDN：Vue 3、Element Plus 2.x、ECharts、可选 Icons |
| UI | 自定义深色大屏壳；EP 仅用于时间窗等轻量控件；`el-*` 必须成对闭合 |
| 数据 | 页面内 mock；字段名 camelCase |
| 打开方式 | 浏览器直接打开，无需 Node 构建 |

## 7. 验收标准

1. 浏览器打开 HTML 后完整渲染左中右三栏与顶栏。  
2. 默认「今日」；切换昨日 / 本周 / 近7天 / 本月后数字与图表有可见变化。  
3. 五组指标区域均有展示内容（非空壳）。  
4. 无真实 HTTP 请求；无 Node 依赖说明要求。  
5. 无 Element Plus 自闭合标签。  

## 8. 风险与说明

| 风险 | 说明 |
|------|------|
| 无在线用户表 | DDL 无独立 online 表；本期不展示「当前在线」，避免虚构口径 |
| mock 与真数差异 | 文档已固定口径，接库时按第 4 节实现即可 |
| CDN 访问 | 默认 jsDelivr；内网演示若失败可换镜像 |
