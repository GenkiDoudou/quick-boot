# 请求来源拦截（CORS）

跨域由 **CORS 防火墙模块** 统一处理（侧栏「请求来源」对应 CORS 策略）。

## 配置

```yaml
qc:
  security:
    firewall:
      cors:
        enabled: true
        allowed-origins:
          - https://admin.example.com
```

生产勿长期使用 `*`，应限定前端域名。

## 类

`FirewallCorsAutoConfiguration`、`FirewallCorsProperties`
