# 防幂等模块

## 用法

Controller 方法上：

```java
@Idempotent
@PostMapping("/create")
public R<Void> create(...) { ... }
```

客户端重复提交时携带请求头（默认 `X-Idempotent-Token`），服务端在 TTL 内占位。

## 配置

```yaml
qc:
  security:
    firewall:
      idempotent:
        enabled: true
        cache-type: caffeine   # 或 redis
        expire-time: 60
        key-prefix: 'qc:idempotent:'
```

## 存储

- 单实例：Caffeine
- 集群：Redis（`cache-type: redis`）
