# 安全登录模块

组合能力，非单类：

| 能力 | 实现 |
|------|------|
| 登录接口 | `AuthController` |
| Token | Sa-Token |
| 验证码 | Tianai + `qc.login.captcha-enabled` |
| 调用方校验 | Client HMAC |
| 登录审计 | `SysLogininfor` |

## 配置

```yaml
qc:
  login:
    captcha-enabled: false
sa-token:
  token-name: Authorization
  timeout: 2592000
```
