# 请求方式与 Host 拦截

## 配置

```yaml
qc:
  security:
    firewall:
      method-and-host:
        enabled: true
        allowed-hosts:
          - localhost:9992
          - admin.example.com
```

## 行为

`MethodAndHostFirewallFilter` 校验 HTTP 方法与 `Host` 头，不在白名单则拒绝。

生产须配置真实域名，勿保留仅 `localhost`。
