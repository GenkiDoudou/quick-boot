# 字段脱敏模块

## 用法

在 Vo 字段上标注 `@Sensitive`，Jackson 序列化时按类型脱敏（手机号、身份证等）。

```java
@Sensitive(strategy = SensitiveStrategy.PHONE)
private String phonenumber;
```

## 策略

见 `quickboot-common` 包 `desensitization`：`SensitiveStrategy` 枚举定义各规则。
