# 日志记录模块（操作日志）

## 采集

AOP 切面自动记录 Controller 调用（`monitor.operlog`）。

排除：

```java
@IgnoreLogger
public R<Void> internal() { ... }
```

## 配置

```yaml
qc:
  monitor:
    operlog:
      capture-enabled: true
      async-enabled: true
      print: false        # 生产建议 false
      export-max-rows: 10000
```

## 查询

管理端「操作日志」→ `SysOperLogController`

## 脱敏

`OperLogSensitiveMasker` 过滤密码等字段。
