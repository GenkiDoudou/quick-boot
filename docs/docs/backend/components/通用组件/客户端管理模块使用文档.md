# 客户端管理模块（使用）

业务实现位于 **web 模块** + **OAuth2 签名校验**，非独立 starter。

## 管理 API

`/system/oauthClient` — 见 [客户端管理](../../modules/client-management)

## 签名校验

`ClientSignService` + `qc.security.client-sign.*`

请求头：`X-Client-Id`、`X-Client-Timestamp`、`X-Client-Nonce`、`X-Client-Signature`

## 前端

`utils/clientSign.js` 与后端 canonical 一致。
