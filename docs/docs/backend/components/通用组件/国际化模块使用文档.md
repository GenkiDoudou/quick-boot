# 国际化模块

## 资源文件

`quickboot-common/src/main/resources/i18n/`：

- `messages_zh_CN.properties`
- `messages_en.properties`

## 使用

```java
I18nUtil.message("error.user.notfound");
```

## 请求语言

客户端请求头：

```http
Accept-Language: en
```

Spring `MessageSource` 与 `spring.messages.basename=i18n/messages` 配合。

## 前端

管理端 UI 默认中文；见 [前端国际化](../../../frontend/i18n)。
