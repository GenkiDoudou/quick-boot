# 密码编码器模块

## 接口

`PasswordCodec`：编码/解码用户密码、OAuth secret 等。

## 算法

- 密码：**BCrypt**
- 可配置字段：**SM4**（`{sm4:...}` 前缀），密钥 `QC_SM4_KEY_HEX`

## 配置

```yaml
qc:
  security:
    firewall:
      password:
        codec:
          sm4: ...   # 见 application-dev.yml 示例
```

实现：`DefaultPasswordCodec`、`FirewallPasswordCodecAutoConfiguration`
