# 敏感词过滤模块

## 配置

```yaml
qc:
  security:
    firewall:
      sensitive-word:
        enabled: true
        whiteList: [classpath:sensitive-word-white.txt]
        blackList: [classpath:sensitive-word-black.txt]
        ignoreUrls: [/login]
        strategy: THROW   # 或 REPLACE
```

## 行为

- 基于 houbb **sensitive-word** 引擎
- 命中黑名单：`THROW` 抛 `SensitiveWordException`；`REPLACE` 替换为 `*`
- JSON Body 经 `SensitiveWordJsonBodyProcessor` 处理

## 类

`SensitiveWordFirewallFilter`、`SensitiveWordEngine`
