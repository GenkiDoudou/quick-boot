# 安全头管理模块

## 配置

```yaml
qc:
  security:
    firewall:
      headers:
        enabled: true
        # exclude-urls: []
        # exclude-from-strict-policy-urls: [/swagger-ui/**]
```

## 行为

`FirewallSecurityHeadersFilter` 注入：

- `X-Content-Type-Options`
- `X-Frame-Options`
- `Content-Security-Policy`（严格策略路径可排除 Swagger）
