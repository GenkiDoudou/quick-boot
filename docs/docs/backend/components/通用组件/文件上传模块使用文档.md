# 文件上传模块

## 抽象

`FileTemplate` 支持**本地磁盘**与 **MinIO**（按配置切换）。

## 配置

见 `application.yml` 中文件存储相关项与 `quickboot-common` 自动配置。

## 接口约定

- 上传返回可访问 URL
- Vo 字段可用 `@FileUrl` 序列化为完整 URL

## 前端

前端可使用 `C7Upload` 组件（`packages/C7Upload`）或 Element Plus `el-upload`，请求走统一 `request.js`。
