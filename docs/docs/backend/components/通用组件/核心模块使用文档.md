# 核心模块（API 与基础）

## 统一响应 `R<T>`

```java
return R.ok(data);
return R.fail("操作失败");
```

## 分页

- 请求：`PageRequest`（pageNum、pageSize）
- 响应：`PageInfo`（rows、total）

## 链路 ID

`TraceIds` 用于日志关联（若启用）。
