# 异常处理模块

## 异常类型

| 类 | 用途 |
|----|------|
| `WarningException` | 可预期业务失败（参数错误、状态不允许） |
| `ErrorException` | 严重错误 |
| `BaseException` | 基类，携带 `ErrorCodes` |

**禁止**在业务代码中用 `IllegalArgumentException` 表示业务失败。

## 全局处理

`@RestControllerAdvice` 统一捕获并转为 `R.fail(code, msg)`，HTTP 状态码多为 200。

常见错误码见 `ErrorCodes` 与 `quick-ui/src/utils/errorCode.js` 映射。

## 国际化

异常消息可通过 `I18nUtil` 与 `messages_zh_CN.properties` 解析。

## 示例

```java
if (user == null) {
    throw new WarningException("用户不存在");
}
```
