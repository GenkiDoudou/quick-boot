# 仓库 .cursor 文件对照

| 路径 | 作用 |
|------|------|
| `AGENTS.md` | 协作总纲、命令、编码约定 |
| `.cursor/rules/*.mdc` | 持久规则（如 karpathy-guidelines） |
| `.cursor/skills/` | 项目内 Skills（OpenSpec、规范生成等） |
| `.cursor/commands/` | 斜杠命令（opsx-apply、opsx-new…） |
| `.codex/skills/` | Codex 侧 OpenSpec 技能副本 |

修改协作流程时同步更新本表与对应 md 文件。
