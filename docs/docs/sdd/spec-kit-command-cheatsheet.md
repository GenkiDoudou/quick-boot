# Spec-Kit / OpenSpec 命令速查

| 命令 | 说明 |
|------|------|
| `opsx-new` | 新建 change |
| `opsx-continue` | 生成下一 artifact |
| `opsx-ff` | 快进生成全部 artifact |
| `opsx-propose` | 一次生成 proposal+design+tasks+specs |
| `opsx-apply` | 按 tasks 实现 |
| `opsx-verify` | 对照 spec 检查 |
| `opsx-sync` | 同步 delta spec 到 main specs |
| `opsx-archive` | 归档完成变更 |
| `opsx-explore` | 探索讨论 |
| `opsx-onboard` | 引导式走通一轮 |

CLI：`openspec list`、`openspec validate`（以实际安装为准）。

Cursor 命令文件：`.cursor/commands/opsx-*.md`
