# 安全防护模块综合设计

## 架构

请求链顺序（示意）：**CORS → 安全头 → XSS → SQL 注入 → 敏感词 → Method/Host → 幂等 → Sa-Token / Client 签名**

各子模块可独立 `enabled: false`。

## 配置根

```yaml
qc:
  security:
    firewall:
      headers: { enabled: true }
      cors: { enabled: true, allowed-origins: ['*'] }
      xss: { enabled: true }
      sql-injection: { enabled: true }
      sensitive-word: { enabled: true, strategy: THROW }
      method-and-host: { enabled: true }
      idempotent: { enabled: true }
```

## 实现包
