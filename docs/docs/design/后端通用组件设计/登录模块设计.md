# 登录模块设计

## 范围

- 账号密码登录 `POST /login`
- 验证码（可选）：`qc.login.captcha-enabled` + Tianai
- 二维码/短信扩展（按实现启用）
- 登出、getInfo、getRouters

## 认证栈

**Sa-Token** Bearer Token，非 JWT。
