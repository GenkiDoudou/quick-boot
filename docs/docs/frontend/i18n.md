# 国际化

## 当前实现

管理端 UI **默认中文**：

- Element Plus：`element-plus/es/locale/lang/zh-cn`（`main.js`）
- 后端业务消息：`quickboot-common` 的 `i18n/messages_zh_CN.properties`、`messages_en.properties`，经 `I18nUtil` 与 `Accept-Language` 解析

前端 **未集成 vue-i18n 全站切换**；若需多语言 UI，建议：

1. 引入 `vue-i18n`，在 `layout` 增加语言切换  
2. 与后端 `spring.messages.basename` 对齐错误码文案  

## 后端切换语言

请求头：

```http
Accept-Language: en
```

异常与校验消息可走英文资源文件。

## 日期与数字

- 展示：`parseTime`（`ruoyi.js`）
- 接口：Jackson `yyyy-MM-dd HH:mm:ss`，时区 `GMT+8`
