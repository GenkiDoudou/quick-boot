# 前端代码规范（总册）

> **说明**：本文为单文件总册，面向 **`quick-ui/`** 工程（根据用户确认选项 **A**）。结论均尽量标注依据（`package.json`、`src/*` 等）；与仓库根目录 `AGENTS.md` 中「前端」描述一致时不再重复展开。

## 概述与使用说明

- **适用范围**：`quick-ui/`（Vue 3 + Vite + Element Plus 管理端 SPA）。新建页面、接口封装、业务组件与样式时按下列章节对照。
- **使用方式**：优先遵守本文件与 `sdd/前端代码规范.md` 冲突时的**以本仓库代码为准**原则；若与 OpenSpec/需求文档冲突，以评审结论为准并回写本文件。
- **可追溯性**：技术栈与目录以 `quick-ui/package.json`、`quick-ui/vite.config.js`、`quick-ui/src/` 为准；路由以 `quick-ui/src/router/index.js` 与 `quick-ui/src/store/modules/permission.js` 为准。

## 工程目录结构

依据 `quick-ui/src/` 实际布局归纳（非虚构模板）：

```text
quick-ui/
├── public/                    # 静态资源（不经打包策略外的处理）
├── vite.config.js             # Vite 主配置
├── vite/plugins/              # Vite 插件拆分（vue、auto-import、svg-icon、compression、setup-extend）
├── index.html
├── package.json
└── src/
    ├── api/                   # 按业务域划分的接口（调用 @/utils/request）
    ├── assets/                # styles、icons/svg、images
    ├── components/          # 布局内通用小块（如 Breadcrumb、SvgIcon、ParentView）
    ├── config/               # env 聚合（env.js）、mobile 等
    ├── directive/            # 自定义指令（如权限 hasPermi、hasRole）
    ├── layout/               # 框架布局与子组件（Navbar、Sidebar、TagsView 等）
    ├── packages/             # 业务增强 C7 组件库 + C7MessageBox
    ├── plugins/              # 全局插件（$tab、$auth、$cache、$modal、$download）
    ├── router/               # 路由表（常量路由；动态路由由 permission store 注入）
    ├── service/              # 部分服务封装（如 baseService）
    ├── store/                # Pinia：modules 按领域拆分
    ├── utils/                # request、auth、dict、ruoyi 工具、validate 等
    ├── views/                # 页面视图（含 system、error、dev、login 等）
    ├── App.vue
    ├── main.js               # 应用引导：全局属性、ElementPlus、installPackages
    └── permission.js         # 路由守卫（token、动态路由、白名单）
```

**职责说明**：

- **`api/`**：仅 HTTP 调用与参数拼装，不写 UI；路径与后端 Controller 对齐（如 `api/system/user.js`）。
- **`views/`**：页面级 SFC；与动态路由中 `component` 路径解析配合（见 `store/modules/permission.js` 的 `import.meta.glob('../../views/**/*.vue')`）。
- **`packages/`**：可复用业务组件，经 `packages/index.js` 统一导出并在 `main.js` 中 `installPackages(app)` **全局注册**。
- **`layout/`**：壳层与侧栏、顶栏、多页签等，不与业务页面混放。

## 文件命名规范

- **Vue 单文件组件**：通用组件目录多用 **PascalCase** 包一层（如 `components/SvgIcon/index.vue`）；页面在 `views/` 下可按业务分子目录（如 `system/user/index.vue`）。
- **JS 模块**：**camelCase**（如 `request.js`、`dict.js`）；路由入口 `router/index.js`。
- **样式**：全局片段可用 **`_` 前缀** partial（如 `_variables.module.scss`），由 `index.scss` 统一 `@import`。
- **Pinia store**：文件如 `store/modules/user.js`，导出 `useXxxStore` 形式（与现有 `useUserStore` 等一致）。
- **C7 组件**：目录名与全局注册名一致，如 `packages/C7Button/index.vue` → 标签 **`C7Button`**。

## 文件存放规范

- **接口**：按域分子目录 `api/system/`、`api/login.js` 等；新增模块新建文件，避免单文件无限膨胀。
- **页面**：放在 `views/` 下与业务域对应的目录；若需被动态路由加载，须落在 **`views/**/*.vue`** glob 覆盖范围内。
- **通用逻辑**：无 UI 的放 `utils/`；跨页面状态放 `store/modules/`。
- **环境相关常量**：优先 `src/config/env.js` 读取 `import.meta.env.VITE_*`，避免在业务中散落魔法字符串。
- **静态图标**：SVG 放 `src/assets/icons/svg/`，通过 svg-sprite 使用（见 `SvgIcon`）。

## 接口调用规范

- **Axios 实例**：默认导出 `src/utils/request.js` 中的 `service`；`baseURL` 为 **`import.meta.env.VITE_APP_BASE_API`**（与 `src/config/env.js` 中 `baseApi` 一致）；超时 **10000ms**。
- **请求头**：默认 `Content-Type: application/json;charset=utf-8`。若接口不需要带 Token，在单请求 `headers` 中设置 **`isToken: false`**（见 `api/login.js`）。
- **鉴权**：存在 Token 时自动附加 **`Authorization: Bearer <token>`**（`getToken()` 来自 `@/utils/auth`）。
- **统一响应**：成功判断以 **`res.data.code === 200`**（或缺省视为 200）为准；`401` 触发重新登录流程；`500` 与其它非 200 通过 `ElMessage` 提示并 `reject`（实现见 `request.js`）。
- **Blob 下载**：使用导出的 **`downloadRequest`** / **`download`**；`downloadRequest` 支持 `returnBlobWithHeaders` 以便解析文件名（JSDoc 见源码）。
- **开发代理**：`vite.config.js` 将 **`/dev-api`** 代理到后端（当前配置 target 为 `http://localhost:9992`，rewrite 去掉前缀）；与 `AGENTS.md` 中示例端口可能不同，**以 `vite.config.js` 为准**。

## 公共样式规范

- **全局入口**：`src/main.js` 引入 `element-plus/dist/index.css`、`@/assets/styles/mobile.scss`、`@/assets/styles/index.scss`。
- **`index.scss` 结构**：依次引入 `variables.module.scss`、`mixin.scss`、`sidebar.scss`、`ruoyi.scss`；含全局 reset、`#app` 尺寸、与 Element Plus 2.10 相关的 z-index 补丁等。
- **组件内样式**：优先 `<style scoped lang="scss">`；需要穿透时使用项目既有深度选择器约定（与 Element Plus 类名配合时注意升级兼容）。
- **主题与变量**：侧栏、变量等集中在 `assets/styles/` 下模块文件，避免在单个业务组件内复制大段色值。

### 列表页样式与代码模板（生成/新建页面必读）

新建或改造 **C7JsonTable 列表页**时，须先打开同域已有页面作对照，**禁止**自造布局壳层或单独引入 `page-tokens.scss` 等页面级 token（除非 `DESIGN.md` 明确要求）。

**标准参照页**（按业务域优先选最近似者）：

| 场景 | 参照文件 | 说明 |
|------|----------|------|
| 系统管理 CRUD 列表 | `quick-ui/src/views/system/config/index.vue` | 增删改查 + 弹窗 + 权限按钮，**默认首选模板** |
| 监控只读/批量操作 | `quick-ui/src/views/monitor/logininfor/index.vue` | 无新增/编辑，工具栏扩展、导出 |
| 在线用户/会话类 | `quick-ui/src/views/monitor/online/index.vue` | 只读列表 + 行内强退 |

**结构约定**（与参照页保持一致）：

- 根节点仅用 **`<div class="app-container">`**（无额外 wrapper class、无 scoped 样式块）。
- 表格统一 **`C7JsonTable`**，`rows-key="data.records"`、`total-key="data.total"`。
- 搜索项：`type` + `span: 8`，`placeholder` 使用「请输入…」「请选择…」中文完整句式。
- 操作列：`{ prop: 'action', label: '操作', columnType: 'slot', slotName: 'action', fixed: 'right' }`，模板插槽 **`#action="{ row }"`**；行内操作用 **`el-button link`** 或 **`c7-button link`**，危险操作用 **`c7-button`** + `confirm`。
- 自定义列：`columnType: 'slot'` + `slotName` 与插槽名一致；字典展示优先 **`c7-dict-tag`** 或 `columnType: 'tag'`。
- 权限：工具栏与行内按钮配 **`v-hasPermi`** / `:xxx-button-permi`，与后端 `perms` 字符串一致。
- 视觉：遵循根目录 **`DESIGN.md`**；表格 `border`/`stripe` 使用 `C7JsonTable` 默认即可，勿在单页覆写表头/行背景色。

**代码生成**：`quickboot-web/src/main/resources/vm/quickboot/index.vue.ftl` 须与本节及 **`system/config`** 页结构同步维护；生成 Vue 页面前须阅读本节与参照页源码。

- **数据来源**：`src/api/menu.js` 的 **`getRouters()`**，在 `permission.js` 守卫中于用户拉取信息后调用 `usePermissionStore().generateRoutes()`。

- **维护约定**：新增菜单对应页面时，确保后端返回的 **组件路径** 与 `views` 下文件路径匹配；外链用 `InnerLink` 等约定组件。

## 字典使用规范

- **后端接口**：按字典类型拉取 **`GET /system/dict/data/type/{dictType}`**（封装为 `getDicts(dictType)`，见 `api/system/dict/data.js`）。
- **前端缓存**：Pinia `dict` store 以 **`{ key: dictType, value: 选项数组 }`** 形式缓存；`useDict` 先读缓存，未命中再请求并 **`setDict`**。
- **选项形态**：拉取后映射为 **`label`（dictLabel）、`value`（dictValue）、`elTagType`（listClass）、`elTagClass`（cssClass）**，供下拉、**`C7DictTag`** 等使用。
- **展示辅助**：`selectDictLabel` / `selectDictLabels`（`utils/ruoyi.js`）用于把值转为文案；入参形态需与当前字典数据结构一致。
- **清理**：store 提供 **`removeDict` / `cleanDict`**，登录切换或必要时由业务调用。

### C7Button

- **定位**：在 `ElButton` 上封装「校验 → 确认 → 异步执行 → 成功判定 → 提示」流水线；**`clickFunction` 为必填**，失败应 **`reject`**，与 `request` 拦截器语义一致。
- **关键 props**：`btnType`（预设）、`debounceDelay`（默认 300ms，`lodash/debounce` leading）、`confirm` / `confirmFn`、`validateRef`、busy/loading 相关等（完整列表与 JSDoc 见组件源码）。
- **事件**：`before-click`、`success`、`error`、`after-click`；用于与表单、列表刷新等联动。

### C7Dialog

- **定位**：统一 **`el-dialog`** 与 **`el-drawer`**（由 **`mode`** 控制），支持默认底栏（取消/确定）与 **`extra`** 插槽等。
- **注意**：透传属性通过 `inheritAttrs` 与 shell 绑定拆分；与 `C7Button` 联用时注意 loading 与关闭时机，避免重复提交。

### C7DictTag

- **定位**：将字典项渲染为 **Tag** 样式，依赖字典项上的 **`elTagType` / `elTagClass`**（由 `useDict` 映射字段）。
- **前提**：同一字典类型已通过 **`useDict`** 或 store 预热，避免渲染期空白闪烁。

### C7MessageBox

- **定位**：对 Element Plus `ElMessageBox` / `ElLoading` 的函数式封装；**取消/关闭路径不向业务抛 reject**（统一映射为带 `action` 的结果），便于 `async/await` 流程。
- **扩展**：`asyncConfirm` 在 `beforeClose` 内等待异步任务；`setMessageBoxDefaults` 做全局默认 options 浅合并。
- **版本**：实现注释要求 **element-plus ^2.10** 行为契约；升级 EP 大版本时需回归弹窗类功能。
