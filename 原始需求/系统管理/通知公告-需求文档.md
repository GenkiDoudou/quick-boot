# 通知公告需求文档

## 1. 页面目标
用于公告内容发布维护，支持查询、增删改。

## 2. 查询与列表
- 条件：公告标题、操作人员、公告类型。
- 字段：公告编号、公告标题、公告类型、状态、创建人、创建时间。

## 3. 核心操作
- 新增公告：录入标题、类型、状态、内容（富文本）。
- 编辑公告：按ID回显并更新。
- 删除公告：单条或批量。

## 4. 表单校验
- 必填：公告标题、公告类型。
- 内容支持富文本编辑器。

## 5. 权限点
- `system:notice:list`
- `system:notice:add`
- `system:notice:edit`
- `system:notice:remove`

## 6. 接口清单

> **与仓库实现一致（2026-05）**：写操作统一为 `POST` 子路径，与 `AGENTS.md` 约定一致；定稿说明见 `docs/superpowers/specs/2026-05-14-notice-announcement-design.md`、OpenSpec 变更 `openspec/changes/notice-announcement/`。

- `GET /system/notice/list` — 分页列表
- `GET /system/notice/{noticeId}` — 详情
- `POST /system/notice/create` — 新增
- `POST /system/notice/update` — 修改
- `POST /system/notice/remove` — 删除（请求体为 ID 数组，支持批量）

## 7. 验收标准
- 新增/编辑后列表及时更新。
- 类型和状态字典显示正确。
