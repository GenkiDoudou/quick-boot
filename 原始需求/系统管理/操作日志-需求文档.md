# 操作日志需求文档

## 1. 页面目标
审计后台用户操作行为，支持检索、排序、详情查看、删除、清空、导出。

## 2. 查询与列表
- 条件：操作地址、系统模块、操作人员、业务类型、操作状态、操作时间区间。
- 默认按操作时间倒序。
- 支持列排序：操作人员、操作日期、耗时。
- 字段：日志编号、系统模块、操作类型、操作人员、IP、状态、操作日期、耗时。

## 3. 核心操作
- 查看详情：展示请求地址、请求方式、操作方法、请求参数、返回参数、异常信息。
- 删除日志：单条/批量。
- 清空日志。
- 导出日志。

## 4. 权限点
- `monitor:operlog:query`
- `monitor:operlog:remove`
- `monitor:operlog:export`

## 5. 接口清单
- `GET /monitor/operlog/list`
- `DELETE /monitor/operlog/{operId}`
- `DELETE /monitor/operlog/clean`
- `POST /monitor/operlog/export`

## 6. 验收标准
- 详情字段与列表行一致且可追溯。
- 清空后列表为空并提示成功。
