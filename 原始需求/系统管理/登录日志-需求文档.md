# 登录日志需求文档

## 1. 页面目标
记录并审计登录行为，支持检索、排序、删除、清空、账户解锁、导出。

## 2. 查询与列表
- 条件：登录地址、用户名、状态、登录时间区间。
- 默认按访问时间倒序，支持用户名与时间排序。
- 字段：访问编号、用户名、IP、登录地点、操作系统、浏览器、状态、描述、访问时间。

## 3. 核心操作
- 删除日志：单条/批量。
- 清空日志。
- 解锁用户：针对选中用户名执行解锁。
- 导出日志。

## 4. 权限点
- `monitor:logininfor:list`
- `monitor:logininfor:remove`
- `monitor:logininfor:unlock`
- `monitor:logininfor:export`

## 5. 接口清单
- `GET /monitor/logininfor/list`
- `DELETE /monitor/logininfor/{infoId}`
- `GET /monitor/logininfor/unlock/{userName}`
- `DELETE /monitor/logininfor/clean`
- `POST /monitor/logininfor/export`

## 6. 验收标准
- 解锁后有明确成功提示。
- 状态字典与日志状态一致显示。
