# 字段脱敏模块（quickboot-common/common/desensitization）原始需求

## 背景
- 接口返回的用户隐私字段（手机号/身份证/银行卡/邮箱等）需要脱敏展示。
- 希望脱敏逻辑对业务无侵入：不改变数据库值，仅影响序列化输出。

## 目标
- 提供字段级注解，标记需要脱敏的字段。
- 支持常见脱敏类型 + 自定义脱敏策略。
- 基于 Jackson 序列化器实现，默认适配 Spring Boot Web JSON 输出。

## 功能需求
### 1. 注解能力
- 提供字段注解 `@Sensitive`：
  - `type`：脱敏类型（默认 `CUSTOM`）
  - `strategy`：自定义策略，仅 `CUSTOM` 时生效，格式 `"start,end"`

### 2. 内置脱敏类型
- `NAME`：保留首字符，其余 `*`
- `ID_CARD`：保留前 6 后 4
- `MOBILE`：保留前 3 后 4
- `BANK_CARD`：保留前 4 后 4
- `EMAIL`：保留 `@` 前 2 位与域名
- `ADDRESS`：保留前 6 位，其余固定 `*`
- `PASSWORD`：固定返回 `******`
- `CUSTOM`：按 `strategy` 指定保留前后位数

### 3. 兼容与兜底
- 字段值为 `null`/空串：不处理，原样输出。
- 字段长度不足以脱敏：原样输出。
- 自定义策略非法：原样输出。

## 配置项
- 无（注解级配置）。

## 依赖与边界
- 依赖：Jackson（序列化扩展）。
- 边界：仅处理 JSON 序列化输出；输入参数校验/日志脱敏不在本模块范围。

## 验收标准
- 标注 `@Sensitive(type=MOBILE)` 的字段输出满足掩码规则。
- 标注 `@Sensitive(type=CUSTOM, strategy=\"3,4\")` 输出中间被 `*` 替换。
- 不影响实体/DTO 在内存中的原始值。
