# 异常体系模块（quickboot-common/common/exception）原始需求

## 背景
- 项目需要统一的错误码、异常基类与全局异常处理，避免 controller 层 scattered try/catch。
- 错误消息需要支持国际化（按 code 从 i18n 资源解析）。

## 目标
- 提供统一的异常基类，携带 `code/msg/args`。
- 区分“警告类异常（可预期）”与“错误类异常（严重）”。
- 提供全局异常处理器，将异常映射为统一响应 `R<Void>` 并设置合适 HTTP 状态。
- 提供错误码常量集合（分段规则）。

## 功能需求
### 1. 异常层级
- `BaseException`：
  - 字段：`code`、`msg`、`args`
  - 支持多构造器（含 cause）
- `WarningException`：用于可预期业务/安全拦截类异常
- `ErrorException`：用于严重错误（系统异常/关键失败）

### 2. 错误码规范
- 分段约定：
  - `1xxxx`：通用错误
  - `2xxxx`：业务错误
  - `3xxxx`：安全相关错误
  - `4xxxx`：系统错误
- 提供常用错误码常量（如：内部错误、参数校验、认证失败、幂等重复、敏感词、XSS、验证码等）。

### 3. 全局异常处理
- 对 `BaseException`/`WarningException` 返回：
  - 响应体：`R.error(code, message)`
  - message 获取：优先 i18n（`I18nUtil.getMessage(code,args,defaultMsg)`），无则回落默认 msg
- 对严重异常返回 500（内部错误）。
- 对特定安全/拦截异常可映射为 401/403/429 等更合适的 HTTP 状态（例如客户端认证、幂等、来源拦截）。

## 配置项
- 国际化资源由 Spring `MessageSource` 提供（如 `i18n/messages_*.properties`）。

## 依赖与边界
- 依赖：通用响应模块 `R`、国际化模块 `I18nUtil`。
- 边界：仅统一异常与响应；业务侧需按规范抛出 `BaseException` 派生类。

## 验收标准
- 抛出 `WarningException(code=xxx)` 能返回 `R` 结构且 message 可从 i18n 解析。
- 未捕获异常统一返回内部错误码与 500 状态（不泄露敏感堆栈给客户端）。
