# 文件上传与存储模块（quickboot-common/common/file）原始需求

## 背景
- 业务需要统一的文件上传/下载/预览能力，支持本地存储与对象存储（MinIO）。
- 前端期望接口返回可直接访问的完整 URL，但数据库通常只存相对路径，要求序列化时自动补全域名。
- 不同业务文件类型（图片/文档等）需要不同的后缀与大小限制。
- 上传过程希望留有业务扩展点（钩子），便于审计、病毒扫描、图片压缩等。

## 目标
- 提供统一接口 `FileTemplate`，屏蔽本地/MinIO 存储差异。
- 支持“分类”配置：限制后缀、限制大小、自动生成相对路径。
- 提供 `@FileUrl` 注解：出参补全 domain、入参剥离 domain，仅持久化相对路径。
- 提供上传前后钩子扩展点，并在上传异常时可回调。
- 防止路径穿越（禁止 `..`、禁止以 `/` 开头的相对路径）。

## 功能需求
### 1. 存储类型
- `qc.file.type=local`：本地文件系统存储
  - 本地根目录可配置，目录不存在需自动创建。
- `qc.file.type=minio`：MinIO 对象存储
  - 需配置 endpoint/accessKey/secretKey/bucket。
  - 支持获取临时访问 URL（presigned）。

### 2. 文件分类与校验
- 每次上传必须指定 `classify`（为空则使用默认分类）。
- 分类配置包括：
  - `limitExt`：允许后缀（逗号分隔）
  - `limitSize`：最大字节数（默认 10MB）
- 默认分类未配置时：
  - 使用一组通用后缀白名单（图片/办公文档）
  - 默认 10MB 限制

### 3. 路径生成规则
- 生成相对路径格式：
  - `{classify}/{yyyy/MM}/{uuid}.{ext}`

### 4. 文件接口能力（FileTemplate）
- `upload(MultipartFile, classify)` / `upload(byte[], filename, classify)`
- `download(relativePath)`：返回 `Resource`
- `view(relativePath)`：返回完整 URL（若未配置 domain，则返回相对路径）
- `getShortUrl(relativePath)`：短链（可选能力，未启用则回落 view）
- `getPresignedUrl(relativePath, expireSeconds)`：MinIO 返回签名 URL，本地可回落为 view
- `delete(relativePath)` / `exists(relativePath)`

### 5. 上传钩子
- 提供 `FileUploadHook`：
  - `beforeUpload`（可阻断上传）
  - `afterUpload`
  - `onError`
- 切面/拦截点：在执行 `FileTemplate.upload(...)` 前后调用钩子，并支持 `@Order` 排序。

### 6. URL 自动补全（序列化/反序列化）
- 提供注解 `@FileUrl(domain="")`：
  - 序列化：值为空或已是完整 URL 直接返回；否则拼接 `domain + "/" + relativePath`。
  - 反序列化：若入参为完整 URL 且包含 domain 前缀，则剥离得到相对路径。
- domain 来源：
  - 注解显式 domain 优先；
  - 否则使用 `qc.file.domain`（模块启动时注入到上下文持有者）。

## 配置项
- 前缀：`qc.file`
  - `enabled`：是否启用（默认 `true`）
  - `type`：`local|minio`（默认 `local`）
  - `domain`：访问域名（如 `https://cdn.example.com`）
  - `defaultClassify`：默认分类（默认 `default`）
  - `classifies[]`：分类配置（`classify/limitExt/limitSize`）
  - `local.path`：本地根目录（默认 `/data/uploads`，为空则使用临时目录）
  - `minio.endpoint/accessKey/secretKey/bucket/pathStyleAccess`
  - `shortUrl.enabled/pathPrefix/storage`（短链能力预留）

## 依赖与边界
- 依赖：Spring Web（MultipartFile/Resource）、（可选）MinIO SDK。
- 边界：
  - 本模块不直接暴露 Controller；上传/下载 API 由业务层调用 `FileTemplate` 实现。
  - 短链服务为可选扩展点（可后续接入 Redis/DB）。

## 验收标准
- 按分类限制后缀与大小，非法上传会被拒绝并返回明确错误。
- 上传成功返回的相对路径符合 `{classify}/{yyyy/MM}/{uuid}.{ext}`。
- `@FileUrl` 标注字段在出参中补全 domain，在入参中可剥离 domain。
- MinIO 模式可获取可用的 presigned URL 并在有效期内访问成功。
