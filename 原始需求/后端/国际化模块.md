# 国际化模块（quickboot-common/common/i18n）原始需求

## 背景
- 错误码/提示语需要根据不同语言环境返回不同文案。
- 希望通过错误码 + 参数的方式统一获取国际化消息，并可提供默认兜底。

## 目标
- 提供 `I18nUtil` 工具类，按 `code/args/locale` 获取国际化文案。
- 支持使用当前请求上下文语言（`LocaleContextHolder`）。

## 功能需求
- `getMessage(code)` / `getMessage(code,args)` / `getMessage(code,args,defaultMessage)`
- 默认 locale：`LocaleContextHolder.getLocale()`。
- 当 `MessageSource` 不存在或解析失败时返回 `defaultMessage`。
- 支持读取当前 locale、设置当前 locale。

## 配置项
- Spring `MessageSource`（如 `spring.messages.basename=i18n/messages`）。

## 依赖与边界
- 依赖：Spring `MessageSource`、`LocaleContextHolder`、Hutool `SpringUtil`。
- 边界：仅提供获取文案能力，不负责维护词条内容。

## 验收标准
- 在 `messages_zh_CN.properties` 存在条目时可正确返回中文文案。
- 当条目不存在时返回默认消息（或 code 字符串）。
