# 应用信息模块（quickboot-common/common/info）原始需求

## 背景
- 前端/运维希望从后端获取项目名称、版本号、版权信息等基础元数据。
- 版本号应尽量自动化（如来自 Git Tag/构建信息）。

## 目标
- 提供 `AppInfoProperties` 作为统一的应用元信息载体（可被 Controller/Actuator 使用）。
- 启动时自动填充：
  - `applicationName`：来自 `spring.application.name`
  - `version`：来自 `git.properties` 的 `git.tag`

## 功能需求
- 配置属性前缀：`qc.appinfo`
- 字段：
  - `applicationName`
  - `applicationTitle`（中文名）
  - `version`
  - `copyright`
  - `data`（扩展 Map）
- 在应用启动后（`PostConstruct`）自动写入 `applicationName/version`。

## 配置项
- `qc.appinfo.application-title`：应用中文名
- `qc.appinfo.copyright`：版权文案
- `qc.appinfo.data.*`：扩展字段
- `git.properties`：由构建插件生成，至少包含 `git.tag`

## 依赖与边界
- 依赖：Spring Boot ConfigurationProperties、构建阶段生成的 `git.properties`。
- 边界：仅提供数据承载与初始化，不负责提供具体 API（由业务层暴露）。

## 验收标准
- 启动后 `AppInfoProperties.version` 与 `git.tag` 一致。
- 未提供 `git.properties` 时可用默认值兜底（如 `1.0`）。
