# C7上传（C7Upload）原始需求

## 背景
- 上传组件需要统一：
  - 文件类型/大小校验
  - 多文件限制
  - v-model 以逗号字符串维护 URL 列表
  - 支持自定义上传请求与响应解析

## 目标
- 基于 `ElUpload` 封装上传逻辑与 URL 列表维护，并提供 uploading 状态。

## 功能需求
- `modelValue`：逗号分隔 URL 字符串。
- 上传方式：
  - 优先 `httpRequest`（自定义上传）
  - 否则使用 `uploadUrl`
- 文件校验：
  - `fileType`（逗号扩展名）限制
  - `fileSize`（MB）限制
- 成功处理：
  - `responseParser(res)` 提取 URL（默认 `res.data.url || res.url`）
  - 追加到 URL 列表并更新 v-model
- 删除处理：从列表中移除对应 url 并更新 v-model。
- 超限：提示并触发 `exceed`。
- 自动生成 tip 文案（可用 `tip` 覆盖）。

## 事件
- `update:modelValue`
- `change(newValue)`
- `success(url,response)`
- `error(error)`
- `remove(url)`
- `exceed`

## 对外能力
- 暴露 `uploading`（基于上传中计数）。

## 验收标准
- 上传成功后 v-model 增加新 url；删除后对应 url 移除。
- 非法类型/超大小会被阻止并提示。
