# C7描述列表（C7Descriptions）原始需求

## 背景
- 详情页需要以“描述列表”的方式展示对象字段，并支持图片/字典标签/链接/复制等常用展示形态。

## 目标
- 基于 `ElDescriptions` 提供“配置驱动”的详情渲染器。

## 功能需求
### 1. 数据与字段配置
- 输入：
  - `data`：对象
  - `items[]`：字段配置（`prop/label/span/...`）
- `prop` 支持点号路径（如 `user.name`）。

### 2. 渲染类型（columnType）
- `tag`：根据 `dictList` 渲染 `ElTag`
- `image`：使用 `ElImage` 预览
- `link`：渲染 `<a>`，支持 `linkHref/linkText/linkTarget`
- `copy` 或 `copyable`：展示文本 + `C7Copy`
- 默认：文本（支持 `formatter` 与空值兜底）
- 支持 `slotName`：优先使用具名 slot 自定义渲染。

### 3. 空值处理
- `defaultEmptyText` 全局空值文案，`item.emptyText` 可覆盖。

## 插槽
- `title/extra`（Descriptions 内置 slot）
- 每个字段支持：`item.slotName` 对应具名 slot

## 验收标准
- 不同 columnType 能正确渲染；空值显示“暂无”（或配置值）。
- 点号 prop 能正确取到嵌套字段。
