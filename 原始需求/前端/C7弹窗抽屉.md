# C7弹窗抽屉（C7Dialog）原始需求

## 背景
- 项目同时使用弹窗（dialog）与抽屉（drawer），但希望统一 footer、确认/取消行为、异步提交 loading 与 v-model 兼容写法。

## 目标
- 一个组件支持两种模式：
  - `mode=dialog` 使用 `ElDialog`
  - `mode=drawer` 使用 `ElDrawer`
- 统一：
  - 标题/内容/底部按钮布局
  - `onConfirm` 异步确认函数（自动 loading、成功自动关闭）
  - `modelValue` 与 `visible` 双 v-model 兼容

## 功能需求
### 1. 显隐控制
- 优先 `v-model:modelValue`，否则兼容 `v-model:visible`。
- 关闭时同时 emit `update:modelValue=false` 与 `update:visible=false`。

### 2. Footer
- `footer=true` 时展示默认 footer：
  - 左侧 `extra` slot
  - 右侧 取消/确定按钮
- 允许完全自定义 `footer` slot。

### 3. 确认行为
- 若传 `onConfirm`：
  - 点击确定后进入内部 loading
  - `onConfirm` 成功则自动关闭
  - 失败不关闭（由业务提示）
- 若未传 `onConfirm`：
  - 仅 emit `confirm`（兼容 emit `submit`）

### 4. 生命周期与清理
- 组件卸载时若仍处于打开状态，应主动关闭以避免残留。

## Props（关键）
- `modelValue/visible/title/mode/footer`
- `confirmText/cancelText/confirmLoading/onConfirm`
- `width(size)/size(drawer)/modalProps`

## 事件
- `open/close/cancel/confirm/submit(兼容)`
- `update:modelValue/update:visible`

## 验收标准
- 弹窗/抽屉模式均可用；默认 footer 的确认按钮可自动 loading 并成功后关闭。
