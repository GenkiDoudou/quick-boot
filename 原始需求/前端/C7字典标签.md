# C7字典标签（C7DictTag）原始需求

## 背景
- 列表/详情经常需要将字典值（value）展示为标签（label），并支持不同 tag 类型与折叠展示。

## 目标
- 输入字典 options + 当前值，输出一个或多个 `ElTag`/纯文本。
- 支持多值（逗号字符串/数组）与折叠显示（+N）。

## 功能需求
- `modelValue` 支持 number/string/array/逗号字符串。
- 匹配规则：按 `String(opt.value) === String(val)` 匹配。
- `max>0` 时仅展示前 max 个，超出用 `+N`：
  - `collapse=true` 时 tooltip 展示超出项 label 列表
- 未匹配值：
  - `showValue=true` 时以 info tag 形式展示原始值
- 为空值时显示 `-`。

## Props（关键）
- `options/modelValue/showValue/separator`
- `size/max/collapse/effect/round`

## 验收标准
- 输入 `"1,2"` 可展示两枚 tag；超出 max 时出现 `+N`。
- 未匹配值在 showValue=true 时仍可展示。
