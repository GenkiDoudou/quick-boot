# C7标题（C7Title）原始需求

## 背景
- 页面区块标题需要统一：字号、加粗、底部装饰线、左侧图标、右侧操作区。

## 目标
- 提供标题组件，支持自定义标签 tag（h1~h6/div/p）与装饰线颜色。

## 功能需求
- `labelSize`：
  - 支持 `h1~h6` 预设
  - 支持自定义单位 `20px/1.2rem/1.2em`
- 装饰线颜色：
  - `decorationColor`（优先）或兼容 `labelColor`
- 支持 `icon`（Element Plus 图标名）与 `#icon` slot 覆盖。
- `showBorder=true` 时显示底部边框线。
- 默认插槽作为右侧 actions 区。

## 插槽
- `icon`
- `title`：自定义标题内容
- 默认：右侧操作区

## 验收标准
- 不同 labelSize 能正确生效；装饰线颜色通过 CSS 变量控制显示。
