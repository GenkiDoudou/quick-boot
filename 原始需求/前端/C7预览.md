# C7预览（C7Preview）原始需求

## 背景
- 列表/详情常需要预览图片、视频或文件；不同场景需要不同触发方式（直接展示封面、按钮触发、文件列表触发）。

## 目标
- 输入逗号分隔 URL 列表，支持三类资源预览：
  - 图片：Element Plus 预览
  - 视频：弹窗内播放
  - 文件：新窗口打开
- 支持 autoDetect 自动识别类型与预览前钩子拦截。

## 功能需求
### 1. 输入与样式
- `urls`：逗号分隔 URL 字符串。
- `width/height` 控制预览容器尺寸（number 自动加 px）。

### 2. 展示类型
- `displayType=image|video|file`
- `autoDetect=true` 时按扩展名识别：
  - 图片：jpg/png/gif/webp/bmp/svg
  - 视频：mp4/webm/ogg/mov/avi
  - 其他为 file

### 3. 触发模式（coverType）
- `none`：直接展示封面
  - image：渲染 `el-image`，支持多张预览
  - video：默认封面 + 播放按钮
  - file：文件封面 + 文件名
- `button`：按钮触发预览（可显示数量角标）
- `file`：以文件列表触发预览（点击条目触发对应预览）

### 4. 视频预览
- 点击视频封面后打开 `el-dialog`，对话框内 `<video controls autoplay>` 播放。
- 关闭时需暂停并重置播放进度。

### 5. 钩子与事件
- `onPreview(url,index)` 返回 false 可阻止预览。
- 触发预览 emit `preview(url,index)`；关闭视频弹窗 emit `close`。

## 验收标准
- 图片可预览多张；视频可弹窗播放并关闭后停止；文件点击新窗口打开。
- button/file 触发模式下行为与 none 模式一致。
