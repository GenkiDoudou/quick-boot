# 组件库安装与导出（quick-ui/src/packages/index.js）原始需求

## 背景
- 项目内存在一组业务增强组件（`C7*`），需要统一注册为全局组件，减少页面重复引入。
- 部分能力（如消息弹窗/Loading）更适合以“函数式工具”方式导出。

## 目标
- 提供一个安装函数 `installPackages(app)`，一次性注册全部 `C7*` 组件。
- 同时提供具名导出，支持按需引入组件与函数式工具。

## 功能需求
### 1. 全局注册
- 安装函数会注册（示例）：
  - `C7Button`、`C7ButtonGroup`、`C7Card`、`C7JsonForm`、`C7JsonTable`、`C7Upload`、`C7Watermark` 等。
- 注册名与组件名保持一致（PascalCase）。

### 2. 具名导出（按需）
- 支持从 `src/packages/index.js` 直接导出：
  - 各 `C7*` 组件
  - 消息弹窗工具：`c7Confirm/c7Alert/c7Prompt/c7DangerConfirm/c7Loading/c7MessageBox/setMessageBoxDefaults`

## 依赖与边界
- 依赖：Vue `app.component` 全局注册机制。
- 边界：不负责自动按需拆包；按需优化由构建侧（Vite）与业务侧引入策略完成。

## 验收标准
- `main.js` 中 `app.use(installPackages)` 后可在任意页面直接使用 `<C7Button />` 等组件。
- 可按需 `import { C7Button, c7Confirm } from '@/packages'` 使用对应能力。
