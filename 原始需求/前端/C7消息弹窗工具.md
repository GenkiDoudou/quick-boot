# C7消息弹窗工具（C7MessageBox）原始需求

## 背景
- 页面中大量 confirm/alert/prompt/危险确认/全局 loading 的调用形式不统一，容易出现交互不一致与重复代码。

## 目标
- 基于 Element Plus `ElMessageBox`/`ElLoading` 提供函数式工具：
  - 返回统一结构化结果（confirm/cancel/close）
  - 支持异步确认自动 loading
  - 支持全局默认配置

## 功能需求
### 1. 全局默认配置
- 提供 `setMessageBoxDefaults(config)` 设置默认项（如按钮文案、可拖拽、点击遮罩不关闭等）。

### 2. 对话框 API
- `c7Confirm(message, title?, options?)`
  - 支持 `asyncConfirm`：执行期间自动 loading，失败可用 `errorNotify` 提示
- `c7Alert(message, title?, options?)`：仅确定按钮
- `c7Prompt(message, title?, options?)`：输入框
- `c7DangerConfirm(...)`：危险操作（红色确认按钮）

### 3. Loading
- `c7Loading(text?, options?)`：返回 `{ close() }`

### 4. 统一返回值
- 所有调用返回 `{ action: 'confirm'|'cancel'|'close', value?: string }`。

## 验收标准
- asyncConfirm 场景下点击确定会显示“处理中...”，执行成功自动关闭，失败保持打开并提示。
- cancel/close 不抛异常，统一返回结构化结果。
