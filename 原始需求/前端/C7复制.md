# C7复制（C7Copy）原始需求

## 背景
- 页面中经常需要复制文本（订单号/密钥/链接），希望统一交互、提示与降级策略。

## 目标
- 提供一个轻量复制组件，支持按钮/图标/文本/自定义可点击区域多种展示模式。
- 支持 Clipboard API 与 `execCommand` 降级。

## 功能需求
### 1. 复制内容
- `text` 支持 String/Number，空值安全（null/undefined → 空字符串）。
- 支持 `getCopyText(text)` 动态生成实际复制内容（支持 Promise）。

### 2. 展示模式
- `mode`：
  - `button`：按钮形式
  - `icon`：图标（可选展示文本）
  - `text`：文本形式可点击
  - `clickable/none`：自定义插槽点击区域（none 兼容）

### 3. 通知与钩子
- `showMessage` 控制提示。
- 支持自定义 `notify(type,message)` 替换默认 `ElMessage`。
- `beforeCopy` 返回 false 可阻止复制。
- `afterCopy` 复制成功后回调。

## 事件
- `copy(text)`
- `success(text)`
- `error(error)`

## 验收标准
- 在现代浏览器下使用 Clipboard API 复制成功并提示。
- 在不支持 Clipboard API 的环境下可降级复制成功。
- `disabled=true` 时不触发复制。
