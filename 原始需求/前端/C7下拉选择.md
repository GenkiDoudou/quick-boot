# C7下拉选择（C7Select）原始需求

## 背景
- 下拉选择组件需要支持：
  - 静态 options
  - 异步加载 options
  - 远程搜索（输入关键字请求后端）
- 多选时需要支持输出数组或逗号字符串。

## 目标
- 基于 `ElSelect` 封装数据加载（含 remote）与输出格式转换。

## 功能需求
### 1. 数据来源
- 静态：`dataList` 或 `options`（别名）优先。
- 异步：`fetchData(fetchParams)` 加载；支持 `resultKey/dataFormatter`。
- `autoLoad=true` 且非 remote 时挂载后自动加载。

### 2. 远程搜索
- `remote=true` 时：
  - 聚焦首次加载全量列表
  - 输入触发 `remote-method` 调用 `fetchData({ ...fetchParams, query })`
  - clear 时 `reloadOnClear=true` 可重新加载

### 3. 多选输出
- `multiple=true` 时内部使用数组；
- `separator=true` 时对外输出逗号字符串，否则输出数组。

## 插槽
- `prefix/label/option/empty`

## 事件
- `update:modelValue`
- `change(valueOrString)`
- `visible-change(open)`
- `loading-change(loading)`

## 对外能力
- 暴露 `loading` 与 `reload()`。

## 验收标准
- remote 搜索输入 query 能触发远程请求并更新选项。
- 多选输出格式按 separator 配置生效。
