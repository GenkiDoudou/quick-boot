# C7日期选择器（C7DatePicker）原始需求

## 背景
- Element Plus 日期选择器在不同 type 下的默认 format/value-format 需要统一约定。
- 范围选择时，项目常希望用一个字符串保存（如 `"2024-01-01,2024-12-31"`），也需要可选输出数组。

## 目标
- 基于 `ElDatePicker` 封装：
  - type 对应默认格式推断
  - 范围值合并/拆分
  - 事件透传

## 功能需求
- `type` 支持常见类型：`date/daterange/datetime/datetimerange/monthrange/yearrange/...`
- `format/valueFormat` 未传时按 type 使用默认映射。
- 范围类型（daterange 等）：
  - `rangeMerge=true` 时对外输出逗号字符串
  - 否则对外输出数组
  - 分隔符由 `rangeSeparator` 控制

## 事件
- `update:modelValue`
- `change/blur/focus`

## 验收标准
- daterange 下外部传入 `"a,b"` 可正确回显为数组并可编辑，输出按配置合并/拆分。
