# C7按钮组（C7ButtonGroup）原始需求

## 背景
- 列表页工具栏按钮数量较多，移动端/窄屏下需要折叠为“更多”下拉以节省空间。
- 既要支持数据驱动（配置数组生成按钮），也要支持 slot（兼容已有写法）。

## 目标
- 提供按钮布局容器：
  - `inline`：全部平铺
  - `dropdown`：全部放入下拉
  - `auto`：最多显示 `maxVisible` 个，其余折叠到“更多”
- 支持 data 模式与 slot 模式，两种方式功能一致。

## 功能需求
### 1. 数据驱动模式
- 通过 `buttons[]` 生成一组 `C7Button`：
  - 支持 `hidden/disabled/icon/label/btnType/clickFunction` 等字段。
- 折叠下拉项点击执行对应 `clickFunction`。

### 2. slot 模式（向后兼容）
- 默认插槽内放置多个 `<C7Button />` 时可自动识别并按规则折叠。
- 折叠后下拉项展示按钮 label（或 btnType 预设 label）。

### 3. UI/交互参数
- 间距：`spacing` 支持预设或数值（px）。
- 响应式：`responsive`（表现为 class 标记，供样式扩展）。
- “更多”按钮可配置：`moreText/moreIcon/moreButtonType/moreButtonPlain/trigger`。

## Props（关键）
- `buttons`、`mode`、`maxVisible`、`spacing`、`size`
- `trigger/moreText/moreIcon/moreButtonType/moreButtonPlain`

## 事件
- `before-command(item)`
- `after-command(item)`

## 对外能力
- 暴露 `forceUpdate()`：用于 slot 动态变化后强制重新计算折叠。

## 验收标准
- `mode=auto,maxVisible=2` 时多余按钮进入下拉且点击能执行原逻辑。
- slot 模式下放入 3 个 `<C7Button/>` 也可正确折叠与显示。
