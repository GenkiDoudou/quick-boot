# C7开关（C7Switch）原始需求

## 背景
- 开关类字段常需要：
  - 切换前确认
  - 异步提交（失败回滚）
  - 字典映射显示文字

## 目标
- 基于 `ElSwitch` 封装点击切换流程与异步变更能力。

## 功能需求
- 值体系：
  - `modelValue/activeValue/inactiveValue`
- 文字：
  - 可显式 `activeText/inactiveText`
  - 或通过 `dictList[{label,value}]` 自动映射
- 点击流程：
  1) `beforeChange(newVal)` 返回 false 取消
  2) 确认：`confirmFn` 优先，否则 `confirmMessage` 弹窗确认
  3) `asyncChange(newVal)`（可选）：执行期间 loading；成功后 emit 更新；失败不 emit（即回滚）
  4) `afterChange(newVal)`（可选）
- 颜色兼容：
  - `activeColor/inactiveColor` 通过 CSS 变量注入

## 事件
- `update:modelValue`
- `change(newVal, oldVal)`
- `cancel`

## 验收标准
- asyncChange 失败时开关不会切换（保持原值）。
- confirmMessage 配置后取消确认会触发 cancel。
