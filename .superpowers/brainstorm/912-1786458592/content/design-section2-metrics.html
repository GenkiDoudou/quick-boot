设计稿 §2：指标 ↔ DDL 映射

所有数值本期为 mock；字段口径对齐现有表，便于以后接真接口

左栏

指标 来源表 口径（真数据时）
总用户sys_userdel_flag=0 计数（全量，不受时间窗）
登录用户数sys_logininfor时间窗内 status=0 的 distinct user_name
登录成功/失败sys_logininforstatus 分组计数
访问页数sys_client_trackdistinct page_visit_id
会话数sys_client_trackdistinct session_id
活跃用户sys_client_trackdistinct user_name（非空）
热门页面 Topsys_client_trackpage_path 聚合排序

中栏

指标 来源表 口径
请求次数sys_oper_log时间窗内记录数
错误次数sys_oper_logstatus ≠ 0
请求/错误趋势sys_oper_log按小时或按日分桶（随时间窗）

右栏

指标 来源表 口径
慢 SQL 次数 / 均耗时 / 最大耗时sys_slow_sqlcount / avg(cost_time) / max(cost_time)
来源分布sys_slow_sqlsql_source 分组（BUSINESS / JIMU 等）
最慢 Topsys_slow_sql按 cost_time 降序取若干条
任务成功/失败sys_job_logstatus 分组
最近失败任务sys_job_log失败记录按 create_time 倒序

中上 KPI 的「慢 SQL / 任务失败」与右栏同源，便于一眼扫异常。
